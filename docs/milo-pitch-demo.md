# Milo pitch rehearsal

Use Milo (PT-1042) throughout.

1. Open `/demo`, select the rehearsal date and click **Reset Milo collar demo**. This restores the saved collar reading and clears that session's generated alert/review. It keeps journals, consultations, medical records, coupons and care plans. It does not reset every action in the presentation.
2. Open `/owner?pet=PT-1042&page=health-id`. Point to visit history, allergies and vaccinations. Milo has no recorded past surgery; do not claim one.
3. In `/demo`, click **Run itch episode · +120 sec**. Return to the owner app and refresh. The current simulator raises a **Flag**, not a Watch. The illustrative threshold rule is not a validated medical model.
4. Tap the health alert, choose **Consult my vet**, and save a video consultation request. This is a stored request, not a confirmed appointment, notification delivery or real call.
5. Use **Vet dashboard ↗** in the owner header to open the same patient's vet workspace. Review home observations and medical records together.
6. In Medical Records, open Milo's **Thoracic X-ray**. It is an illustrative reference image, copied into a separate fictional study record for Milo; no real partner machine feed is connected. The report is already reviewed/shared and appears in PET ID from the start. It does not arrive dynamically during the pitch.
7. Return to PET ID and open the image under Imaging & reports. New result review and owner sharing can be demonstrated via existing result import/review, but this version does not add a consultation-note editor or surgery module.

Suggested wording: “One shared summary of the records available to the owner” rather than “every record, readable by any vet.” The prototype has fictional data and no authenticated cross-hospital access.
